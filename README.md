# Badiga Secondary School Management System

A practice project that manages three offices of a Rwandan secondary school:
the library, the discipline office and the director of studies office.

## Status

Early development: planning phase.

## Planned features

- Library: books, loans, returns and fines
- Discipline office: incident records and statistics
- Director of studies office: grades, timetables and class reports
- Dashboards with charts, and downloadable reports
- A chatbot that answers questions using each user's permissions
- Works on desktop and mobile

## Users (staff)

Head teacher, IT, director of studies, director of discipline, librarian
and class representatives. Each user sees only what their job needs.

## Data

This project uses **synthetic (fake) data only**. No real student information
is stored here.

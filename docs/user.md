# Users of the Badiga system

This document lists the staff who use the system. It follows the principle of
**least privilege**: each person gets only the access their job needs.
Anything not listed here is denied.

## Head teacher

**Who:** Leads the school.
**Needs to:**

- See school-wide dashboards (academics, discipline counts, library statistics)
- Approve each class's semester report
- Download term summary reports
  **Must NOT:** Edit raw records such as grades, discipline cases or loans.

## IT

**Who:** Looks after the system's technical side.
**Needs to:**

- Create, disable and reset staff accounts and assign roles
- Read the audit log (who did what, and when)
- Run and verify backups
  **Must NOT:** Read grades, discipline cases or library records.

## Director of studies

**Who:** Runs the academic side of the school.
**Needs to:**

- Enter and correct grades
- Manage timetables
- Review each class's semester report
- See discipline counts (numbers only)
  **Must NOT:** Read the details of discipline cases.

## Director of discipline

**Who:** Handles student behaviour and discipline.
**Needs to:**

- Record incidents for students
- Update a case's status (open, under review, resolved)
- See incident statistics by type and month
  **Must NOT:** See students' grades.

## Librarian

**Who:** Manages the school library.
**Needs to:**

- Add, edit and remove books
- Lend books to students and record due dates
- Record returns and fines
  **Must NOT:** See grades or discipline records.

## Class representative

**Who:** A student leader who represents one class.
**Needs to:**

- Submit the semester report for their own class
  **Must NOT:** Read anything in the system, or submit a report for another class.
